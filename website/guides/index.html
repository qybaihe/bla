Technical Architecture Guides

How BLA Protects Build Artifacts

Each protection pass is designed around the static analyzers, resource caps, and evidence rules used by automated reverse-engineering pipelines.

01 · Resource Budget Guards

Saturate Static & Semantic Limits

Triggers analyzer admission caps with O(1) runtime identities inside unreachable branches.

View Analyzer Limit Mapping
• SEMANTIC_PRIMITIVE_CANDIDATE_LIMIT = 256 -> 9-chunk opaque ternary (512) • SEMANTIC_ALIAS_SELECTION_LIMIT = 512 -> 528+ dynamic selector states • SEMANTIC_PRIMITIVE_JSON_BYTES_LIMIT = 1 MiB -> (codeUnits * 6 + 2) expansion • ReconstructionObligationPolicies -> 22-family obligation expansion
02 · Evidence & Control-Flow Decoys

Demote Real Paths, Surface Decoy Logic

Demotes core business logic to status: "unknown" under static inspection while presenting self-consistent shadow state machines.

View Shadow Business Logic Strategy
1. Demote real logic to status: "unknown" via static budget guards. 2. Provide self-consistent Shadow Business Logic (Shamir-Ed25519 rings, tiered billing matrices, TPM2 PCR0 quotes). 3. Include enclave delegation metadata (vsock CID 16) and decoy VLQ source maps.
03 · One-Command Workflow

MCP Server, CLI & Bundler Plugins

Run npx bla-agents setup to register with Claude Code, Cursor, Codex, Windsurf, or Gemini CLI, then run the protection pipeline with bla_harden.

View 4-Stage Agent Closed Loop
Stage 1 · Recon: bla_audit + inspectReleaseExposure Stage 2 · Plan: bla_weave_plan (identifies sensitive branches & sidecar bindings) Stage 3 · Verify Weave: bla_verify_weave (validates source-level decoy surgery) Stage 4 · Seal & Verify: bla_harden + bla_verify (atomic write + runtime equivalence)
04 · Runtime & Integrity Binding

Self-Seal Digest & Sidecar Entanglement

Binds entry points to sibling artifacts and runtime memory masks so stripping a decoy table or sidecar module fails closed at load time.

View Integrity & Memory-Diff Defenses
• Self-Seal: final-byte digest finalized at the atomic write chokepoint • Sidecar Entanglement: binds JS, Python, and WASM entries to sibling SHA-256 digests • Split-Share XOR Memory Shield: masks M0 -> M1 heap snapshot diffing
