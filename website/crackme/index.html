CrackMe v6 — BLA-generated challenge

Test a target that was genuinely hardened by BLA — not a hand-written CTF sponge.

Why v6

CrackMe v5.x was a custom crypto construction. v6 rebuilds the challenge around the product claim: run bla protect / the bla harden engine on a clean Node.js license gate and publish the output.

Tiers

  • L1 — balanced (default harden surface)
  • L2 — maximum
  • L3 — bankrupt + --llm-directives

Run

env -u NODE_OPTIONS node challenge/v6/artifacts/L1.cjs '<authorization-key>'

Submit a solve

Hash the FLAG with SHA-256 and open a GitHub issue using the CrackMe v6 solve template. The hash must match flagSha256 in the public commitment file (plaintext FLAG is not in git).

Open challenge/v6 on GitHub

Honest scope

BLA raises cost for automated AI reverse-engineering agents and plants decoys. It does not claim immunity to patient interactive human reverse engineering.
