    Where the status lives

    challenge/README.md in the repository is the maintained status table. This website does not keep a second copy of that table, and it does not turn GitHub issues or CI into a solved count.

    What a public solve must match

    The current challenge directory is linked from the status panel after the repository file loads. A solve is a FLAG whose SHA-256 equals flagSha256 in that version's SEAL.json. Plaintext key and FLAG are not in git.

    Submit a solve

    Use the issue template for the version you solved. The status panel shows the flagSha256 published in the current SEAL.json.

    Honest scope

    BLA raises cost for automated AI reverse-engineering agents and plants decoys. It does not claim immunity to patient interactive human reverse engineering. The panel does not report a live break count.
