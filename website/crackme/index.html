    02 · Verification Rules

    What a public solve must match

    • The current challenge directory is linked from the status panel after the repository file loads.
    • A solve is a FLAG whose SHA-256 equals flagSha256 in that version's SEAL.json.
    • Plaintext key and FLAG are not in git. Issue templates collect submissions; they are not a confirmed-solve tally.
