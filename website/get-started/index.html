Quick Start

Configure Your Agent or Run from the Terminal

Requires Node.js 22.13+ or 24+. No external compilers or third-party packers required.

Step 1 · Agent MCP Setup

Register BLA with Your Coding Agent

Configures Claude Code, Cursor, Codex, Windsurf, Gemini CLI, and Antigravity with the bla MCP server and blind-llm-agents skill. 

npx bla-agents@latest setup --all-detected --yes
Step 2 · 5-Stage Protection Pipeline

Audit, Protect, and Verify in One Command

Runs source-map exposure checks, static audit, format-specific protection, and runtime equivalence verification. Pass --manifest only if you want an unsigned attestation JSON next to artifacts. 

npx bla-agents@latest harden .
Agent & Bundler Integration

Use Natural Language or Build Plugins

Agent Prompt

Prompt for Claude Code / Cursor

Once setup is complete, ask your coding agent:

"Harden my software against REA (bla_harden on the project directory)."
Build Bundler Plugin

Build-Time Protection

Integrates with Vite, Rollup, Webpack, and esbuild:

import { blaVitePlugin } from "bla-agents/bundler";

export default {
  plugins: [blaVitePlugin({ intensity: "bankrupt" })],
};
