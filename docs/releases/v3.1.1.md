# bla-agents v3.1.1 — Multi-Language Weave Hardening, WASM Sidecar Entanglement & Babel 8

**Date:** 2026-11-08 (America/Los_Angeles)

## Headline

Patch release upgrading `@babel/*` to v8.1.0, adding WASM custom-section sidecar strip⇒fail entanglement (`bla.sidecar.v1`), hardening the JS/TS, Python, and Native (`C/C++/Rust/Go`) surgical planner and weave verifier from end-to-end subagent dogfooding, and enabling recursive directory discovery in `bla_encrypt_strings`.

## Added

- **Sidecar WASM custom-section strip⇒fail (`bla.sidecar.v1`):** `generateSidecarWasmCustomSection`, `bindWasmSidecarEntanglement`, `entangleWasmEntryWithSidecars`, and `verifyWasmSidecarCustomSection` bind sibling artifacts into WASM custom sections without altering the export ABI.
- **JS/TS, Python & Native Planner/Verifier Hardening (`src/shields/weave/weave-decoy.ts`):**
  - JS/TS: ES6 class method & `export default` discovery, `Map`/`Set`/deep-property & parameter-passed shared-state tracking, fail-closed `return false` guard allowance alongside `!0`/`!1`, boolean ternary, unused helper binding, and template-literal secret detection.
  - Python: indentation-aware `extractPythonFunctions` (`async def`, multi-line signatures, blank lines, class methods) and Check 7 gate coupling + lane-independence lint.
  - Native C/C++/Rust/Go: pointer return signatures, `pub(crate)`/`async`/`unsafe`/`const fn`, Go `var (...)` blocks, and `strncmp`/`memcmp` secret checks.
- **Recursive `bla_encrypt_strings` Discovery:** recursively scans `.js`/`.ts`/`.cjs`/`.mjs`/`.html` files under project directories while preserving relative paths.

## Fixed

- **Babel 8 (`@babel/*` v8.1.0) Compatibility (#128, #131):** aligned AST CJS/ESM interop and `ExportNamespaceSpecifier.exported` typing so `tsc --noEmit` passes cleanly.
- **`bla_emit_headers` & `bla_verify_weave` Coexistence (#131):** scrubbed `BLA-SHIELD` marker text from emitted `bla_shield.{h,rs,go}` headers and excluded generated shield headers from directory weave verification.
